# Remymy (a.k.a Remy2): Yet another suggestion service for what to eat today?

Remymy is the client-side application with the goal to let user to have one interface for meal suggestion, based on the user preferences.

Written in React, NextJS based on pi-coding-agent framework and its components for client side app.

This application interact with the recommender models through an interal MCP server (version 2.0), through jsonrpc.
